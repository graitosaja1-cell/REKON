Periksa mana faktur yang sudah dibayar dan mana yang belum

Unggah dua file Excel: data Penjualan dan data Uang Masuk. Alat ini mencocokkan keduanya bukan hanya lewat nomor faktur, tetapi juga lewat nominal, nama toko/customer, alamat, sales, kategori produk (Minyak / Rupa-rupa) dan jenis pembayaran (Cash -> Dropping, Tempo -> Piutang). Semua proses berjalan di komputer/handphone Anda sendiri - file tidak diunggah ke mana pun.

1. Data Penjualan

Contoh: Rekap_Penjualan_Hasil.xlsx
Kolom: TANGGAL, NO. FAKTUR, PRODUK, SALES, PEMBAYARAN, CUSTOMER, ALAMAT

Klik atau tarik file Excel ke sini

Panduan singkat

Cara alat ini mencocokkan

  1. Nomor faktur sama -> dianggap satu tagihan (versi paling kuat).
  2. Nomor faktur beda sedikit (kurang/lebih 1 angka) -> dipasangkan otomatis dan ditandai Salah Ketik.
  3. Nomor faktur mirip (beda 1 angka / dua angka tertukar) -> digabungkan hanya bila nama toko atau alamat mendukung.
  4. Nomor faktur beda jauh, tetapi nama toko + alamat + tanggal + nominal sama -> dipasangkan dengan tanda Cocok via Toko/Nominal.
  5. Mode Longgar (opsional) -> cocokkan walau nomor faktur beda bulan, dengan bukti: toko + alamat + kategori + jenis + nominal.
  6. Abaikan Faktur (opsional) -> cocokkan murni dari data non-faktur (untuk periode berbeda).

Aturan kategori & jenis

  • Produk mengandung "FITRI" -> kategori Minyak; produk lain -> Rupa-rupa.
  • Penjualan PEMBAYARAN = CASH -> uang masuk harus Dropping.
  • Penjualan PEMBAYARAN = TEMPO -> uang masuk harus Piutang.
  • Kategori uang masuk dibaca dari kolom nominal (Minyak_Cash, Minyak_Transfer, Rupa2_Cash, Rupa2_Transfer).

Sisa / tagihan bulan lalu

Uang masuk sering memuat faktur bulan lalu yang tidak ada di file penjualan periode ini. Baris seperti itu diberi status Faktur tidak ada di Penjualan dengan catatan Tagihan bulan lalu, dan sisa dihitung dari kolom Tagihan di uang masuk.

Kolom yang dikenali otomatis

Nama kolom boleh berbeda ejaannya. Alat menebak sendiri pasangan kolomnya: No Faktur, Tanggal, Tagihan, Total, Nama Toko, Customer, Alamat, Sales, Pembayaran, Jenis, Kategori/Pembayaran, Ket, PRODUK. Jika salah, ganti kolom manual di bawah kotak unggah.

Batas alat ini

Hasil cocok otomatis adalah usulan. Pasangan yang ditandai Salah Ketik / Cocok via Toko / Perlu dicek / Mode Longgar sebaiknya diverifikasi manusia sebelum dipakai untuk penagihan.

Bentuk file yang dihasilkan

Unduh Hasil (Excel) membuat 1 file dengan sheet: Ringkasan, Rekap Faktur, Belum Bayar, Bayar Sebagian, Lunas, Lebih Bayar, Faktur Tak Ditemukan, Salah Ketik Faktur, Perlu Dicek, Rincian Uang Masuk, dan Ringkasan Sales.
